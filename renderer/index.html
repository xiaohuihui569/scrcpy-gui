使用教程

        
      

      

        
    
          
  1. 
            连接手机
            用数据线连接手机，手机上开启「开发者选项 → USB 调试」。设备会自动出现在左侧列表，带蓝色「有线」标签。
          
    2. 
          
  2. 
            开启网络调试（可选）
            先选中手机，端口框会自动填入 Wi-Fi IP，默认 5555。点「开启网络调试」后手机会弹出确认，点允许后即可拔掉 USB 线。
          
    3. 
          
  3. 
            启动镜像
            点「启动镜像」后会弹出原生 scrcpy 窗口，画面由原生窗口展示，模拟器本身不渲染画面。
          
    4. 
          
  4. 
            快捷操作
            返回、主页、音量、电源等按钮通过 ADB 立即生效，无需重启。截图会保存到图片文件夹。
          
    5. 
          
  5. 
            镜像参数
            分画质、窗口、音视频等分组设置。改动后顶部会出现「参数已修改」提示，点「重启镜像」生效。
          
    6. 
          
  6. 
            重命名与标注
            双击左侧设备名称可修改（回车保存，留空清除）。名称按机型保存，无线设备 IP 变了也不会丢。绿色「无线」与蓝色「有线」标签区分连接方式。
          
    7. 
        

        

          快捷键
          Ctrl+R重启镜像
          Delete停止
          F5刷新设备
          Ctrl+,设置
